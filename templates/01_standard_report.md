# Template 1: Standard Trend Report

**When to use:** Weekly trend reports, portfolio updates, comprehensive analysis

---

## Prompt Template

```
TREND INTELLIGENCE REQUEST

Apply my [Trend Intelligence Methodology v1.0] to generate a report with:

**Specifications:**
- Verticals: [Select 3-5 from: Consumer Tech, B2B SaaS, FinTech, HealthTech, EdTech, E-commerce/DTC, Climate Tech, Web3/Crypto, Creator Economy, Supply Chain/Logistics, Workplace Tools, Media/Entertainment]
- Regions: [NA/EU/APAC/LATAM/MEA - choose 1-2 primary]
- Time Horizon: [Emerging/Accelerating/Mainstream/Mature/Declining - choose focus, or "All stages"]
- Date: [Today's date]

**Scope:**
- Target: [5-7] trends total
- Depth: [300-400] words per trend
- Prioritize: [Depth/Breadth - choose one]

**Method:**
- Data: Use web_search for signals from past [30/60/90] days
- Focus: Trends relevant to [describe your domain/audience/investment thesis]
- Format: Standard newsletter structure from framework

**Output:** Include all 5 newsletter sections:
1. Top Trends (with full evidence citations)
2. Flash Futures
3. Regional Migration Map
4. Tracker Update (if applicable)
5. Strategic Synthesis

**Special Instructions:** [Optional: any specific focus areas, exclusions, or emphasis]
```

## Example Usage

```
TREND INTELLIGENCE REQUEST

Apply my [Trend Intelligence Methodology v1.0] to generate a report with:

**Specifications:**
- Verticals: B2B SaaS, Workplace Tools, AI/ML Tools
- Regions: North America (primary), EU (secondary)
- Time Horizon: Emerging and Accelerating (focus on early-stage)
- Date: October 23, 2025

**Scope:**
- Target: 5 trends total
- Depth: 400 words per trend
- Prioritize: Depth over breadth

**Method:**
- Data: Use web_search for signals from past 45 days
- Focus: Trends relevant to B2B software product development and GTM strategy
- Format: Standard newsletter structure from framework

**Output:** Include all 5 newsletter sections plus confidence score breakdowns

**Special Instructions:** For each trend, include a "Build vs. Buy vs. Partner" analysis
```

---

## Expected Output Structure

### Header
```
Date: 23 Oct 2025 | Edition: #1 | Focus: B2B SaaS, Workplace Tools, AI/ML
```

### Section 1: Top Trends
5 trends with:
- Confidence score and visual indicator (🟢/🟡/🔴)
- Stage and regions
- What It Is (2-3 sentences)
- The Evidence (4-6 cited data points)
- Why It Matters (market implications)
- Action Recommendation (specific to confidence level)
- Confidence Breakdown (scoring explanation)

### Section 2: Flash Futures
- 3-5 weak signals
- Surprising moves
- Contrarian take

### Section 3: Regional Migration Map
- Table with trend-by-region breakdown
- Regional insights paragraph

### Section 4: Tracker Update
- Top gainers and decliners
- Portfolio changes

### Section 5: Strategic Synthesis
- Portfolio composition stats
- Cross-trend themes
- 30-day watchlist
- One actionable recommendation

---

## Output Quality Checklist

Before accepting the output, verify:
- [ ] All data points have source citations with dates
- [ ] Confidence scores show calculation breakdown
- [ ] Each trend has 4-6 specific evidence points
- [ ] Action recommendations match confidence levels
- [ ] Regional claims backed by regional sources
- [ ] No speculation without clear labeling
- [ ] Disclaimer section included at bottom

---

## Customization Options

**Adjust scope based on your needs:**

**Quick version:**
- 3 trends instead of 5-7
- 200-250 words per trend
- Skip sections 2-4, focus on Top Trends only

**Deep version:**
- 7-10 trends
- 500+ words per trend
- Add competitive landscape analysis to each trend
- Include market sizing where available

**Rapid update:**
- Keep same trends from last report
- Just update confidence scores and new data points
- Focus on "what changed" rather than full analysis

**Vertical-specific:**
- Single vertical deep dive
- 10-15 trends in that vertical only
- Include vertical-specific metrics (e.g., CAC payback for SaaS)
