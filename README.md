# Trend Intelligence Framework

**Version 1.0** | **Last Updated:** October 23, 2025

A comprehensive, evidence-based framework for analyzing emerging commercial, technological, and cultural trends.

---

## 🎯 What This Framework Does

This framework helps you:
- **Identify emerging trends** before they hit mainstream (0-20% awareness)
- **Assess confidence** using a rigorous 0-100 scoring system
- **Track lifecycle stages** from Emerging → Accelerating → Mainstream → Mature → Declining
- **Make data-driven decisions** on resource allocation and strategic positioning
- **Avoid false positives** through disciplined source evaluation and kill signals

**Core Philosophy:** Trends are hypotheses requiring continuous validation, not facts. This methodology prioritizes early-stage pattern recognition, multi-regional perspective, confidence-weighted analysis, and portfolio management.

## 📋 Core Framework Components

### 1. **Source Reliability System** (3-Tier)

| Tier | Reliability | Examples |
|------|-------------|----------|
| **Tier 1** | High | Google Trends data, SEC filings, Gartner reports, BLS data |
| **Tier 2** | Moderate | TechCrunch, Bloomberg, Morning Brew (with citations) |
| **Tier 3** | Exploratory | Reddit (>100 upvotes), Twitter threads, Discord communities |

📖 [Full Source Tier Guide](quick_reference/source_tiers.md)

---

### 2. **Confidence Scoring System** (0-100 scale)

**Formula:** Average 4 dimensions, round to nearest integer

| Dimension | Weight | Key Question |
|-----------|--------|--------------|
| **A: Source Quality** | 25% | How reliable are your sources? |
| **B: Signal Strength** | 25% | Do you have quantitative data, multi-platform presence, geographic spread? |
| **C: Coherence** | 25% | Is there a clear narrative, catalyst, and monetization path? |
| **D: Timing** | 25% | How recent is the data? |

**Action Thresholds:**
- 🟢 **80-100% (Green):** ACT - Invest, build, commit resources
- 🟡 **60-79% (Yellow):** TEST - Pilot, monitor, define exit criteria
- 🔴 **0-59% (Red):** WATCH - Track only, no resource commitment

📖 [Full Confidence Scoring Guide](quick_reference/confidence_scoring.md)

---

### 3. **Trend Lifecycle Stages** (5 stages)

| Stage | Awareness | Characteristics | Action |
|-------|-----------|-----------------|--------|
| **Emerging** | 0-15% | Niche discussions, early adopters, limited products | Small bets, experimentation |
| **Accelerating** | 15-40% | Multi-platform buzz, mainstream media, retail expansion | Scale pilots, commit resources |
| **Mainstream** | 40-70% | Peak media, saturation in early adopters, corporate adoption | Differentiation, efficiency |
| **Mature** | 70%+ | Ubiquitous, incremental innovation, consolidation | Value optimization, adjacencies |
| **Declining** | Negative | Substitutes emerging, negative media, usage falling | Exit or contrarian play |

📖 [Full Lifecycle Stage Guide](quick_reference/lifecycle_stages.md)

---

### 4. **Portfolio Management Rules**

- **Maximum active trends:** 15 (focus > coverage)
- **Target distribution:** 3-5 Green, 5-8 Yellow, 2-4 Red
- **Review cadence:** Weekly updates, monthly deep dives, quarterly backtests
- **Kill signals:** Confidence drops ≥20 pts in 30 days, fails validation 3x, negative catalyst
- **Revival signals:** Confidence recovers ≥15 pts in 60 days, new Tier-1 data, geographic expansion

## 📊 Quality Control Standards

**Before publishing any analysis:**

- [ ] All Tier-1 claims have ≥2 independent sources cited
- [ ] Dates included for all data points
- [ ] Confidence score calculated using all 4 dimensions
- [ ] No 80%+ scores without ≥2 Tier-1 sources
- [ ] Stage assignment based on observable metrics
- [ ] Regional claims backed by regional sources
- [ ] Clear distinction between "what we know" and "what we infer"
- [ ] Disclaimer included acknowledging limitations

## ⚠️ Limitations & Disclosures

**Always include in reports:**

1. **Prediction Disclaimer:** Confidence scores measure evidence strength, not outcome certainty. Early-stage trends have 40-60% failure rates even with strong signals.

2. **Data Constraints:** Analysis based on available sources (web search, reports, etc.). Real-time platform metrics not directly accessible; assessments based on secondary reporting.

3. **Regional Coverage:** Analysis limited by language barriers, source availability, and market access. Specify which regions have stronger/weaker coverage.

4. **Temporal Limitations:** Trend intelligence is time-sensitive. Confidence scores degrade as data ages. Reassessment recommended every 7-30 days.

📖 Full disclosures: [Framework Methodology - Limitations](framework/Trend_Intelligence_Methodology_v1.0.md#limitations--disclosures)
